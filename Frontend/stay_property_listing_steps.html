Stay Property Listing Specification

A comprehensive guide to inputs, variables, data structures, and mock payloads for the 9-step hosting form.

Document Type

Technical Reference Sheet

Target Component

StayPropertyForm.jsx

Total Steps

9 Categories

Output Format

JSON Schema & Mock Payloads

1

Basic Information

Collects the property title and primary category type.

Field Name State Variable Type Validation Description
Property Name propertyName String Required Display title of the property listing.
Property Type propertyType String (Enum) Required Hotel, Apartment, Hut House, Resort, Beach House, Villa.
Step 1 Mock Data (Payload)
{
  "propertyName": "Greenwood Whispering Pines Resort",
  "propertyType": "Resort"
}
2

Location Details

Gathers physical address components and map coordinate markers.

Field Name State Variable Type Validation Description
Address Line 1 addressLine1 String Required Street name, plot number, building address.
Address Line 2 addressLine2 String Optional Locality, suite, landmark.
City city String Required City of listing.
State stateVal String Required State or union territory.
Country countryVal String Required Country.
ZIP Code zipVal String Required Postal code.

  "city": "Kodaikanal",
  "stateVal": "Tamil Nadu",
  "countryVal": "India",
  "zipVal": "624101"
}
3

Room Setup

Configures room inventory, quantities, floors, and individual adult/child capacity capacities.

Field Name State Variable Type Validation Description
Selected Room Types selectedRoomPills Array<String> Required E.g. Single, Double, Triple, Suite, 1 BHK, 2 BHK.
Room Configs roomConfigs Object Required Maps room type keys to floor and quantity selections.
Room Capacities roomCapacities Object (Array) Required Array containing {adults, children} for each room unit.

4

Pricing & Availability

Defines pricing structures, extra occupant charges, child thresholds, and add-on bedding pricing.

Field Name State Variable Type Validation Description
Base Room Prices roomPrices Object (Number) Required Nightly rate per room type in Indian Rupees (₹).
Occupancy Adjustments occupancyAdjustments Object (Array) Optional Adds dynamic extra guest pricing values.
Child Age Rules childAgeRanges Array<Object> Optional Custom child age brackets and fixed/percentage fee details.
Extra Mattress (Child) extraMattressChild Number Optional Cost per child extra mattress.
Extra Mattress (Adult) extraMattressAdult Number Optional Cost per adult extra mattress.
Extra Cot Cost extraCotCost Number Optional Cost per extra cot / rollaway bed.

Property Rules & Policies

Sets hospitality operational parameters, check-in schedules, pet/couple filters, and refund options.

Field Name State Variable Type Validation Description
Check-in Time checkInTime String Required Standard check-in hour (e.g. "12:00").
Check-out Time checkOutTime String Required Standard check-out hour (e.g. "10:00").
Accepted ID Proofs acceptedIds Array<String> Required "Passport", "Aadhar", "Govt ID", "Driving License".
Rules Statuses Toggles (multiple) String ("Yes" / "No") Required Smoking, Alcohol, Unmarried Couples, Non-veg, Pets.
Refund Policies refundPolicies Array<Object> Required List of cancellation refund milestones.

8

About this property

Stores transit connectivity details, guest filters, approval channels, and a narrative description.

Field Name State Variable Type Validation Description
Distance - Beach distanceBeach String (Number) Required Distance to nearest beach in kilometers.
Distance - Railway distanceRailway String (Number) Required Distance to nearest railway station in kilometers.
Distance - Airport distanceAirport String (Number) Required Distance to nearest airport in kilometers.
Distance - Bus Stand distanceBus String (Number) Required Distance to nearest bus stop in kilometers.
Allowed Guest Types allowedGuestTypes Array<String> Required "Married Couples", "Families", "Solo Travelers", "Friends".
Booking Setup instantBooking, manualApproval String ("Yes" / "No") Required Determine if requests need approval or book instantly.
Property Description aboutPropertyText String (Rich HTML) Required Detailed marketing text about the property.

9

Legal Info

Filing details for owner identity, property ownership, tax registrations, safety NOCs, and bank payouts.

Field Name State Variable Type Validation Description
Property Owner Name ownerName String Required Full name of the property owner.
Aadhaar Number ownerAadhar String Required 12-digit Aadhaar national identification number.
Owner Photo ownerPhoto Image File Required Photo of the property owner for profile authentication.
Ownership Proof ownershipProof Document File Required Sale Deed / Lease Agreement / Municipal Tax Receipt.
Business Name businessName String Required Registered owner name or corporate entity name.
Business PAN pan String Required 10-character alphanumeric Permanent Account Number.
GSTIN gstin String Optional 15-character Goods and Services Tax Identification Number.
Property License Number licenseNumber String Required Tourism commission or local municipal lodging registration.
Trade License tradeLicense String Optional Municipal commercial trade permit code.
Fire Safety NOC fireSafetyNumber String Required Fire department clearance NOC certificate ID.
Bank Account Name bankAccountName String Required Name of the bank account holder.
Bank Account Number bankAccountNumber String Required Bank account number for payouts.
IFSC Code ifscCode String Required 11-character Indian Financial System Code.
Cancelled Cheque cancelledCheque Document File Required Cancelled cheque image or bank passbook page.
Declaration Certified isLegalDeclared Boolean Required User must explicitly toggle true to enable submission.
